Building StoryCosmos: Where AI Meets Creative Writing

Exploring how large language models can understand a writer’s scene and surface relevant visual references.

By Mariam FatimaJuly 20266 min read
SC
In this articleThe ideaHow the pipeline worksDesigning the editorWhat I learned

The idea

StoryCosmos is an AI-assisted writing application designed to make visual discovery part of the writing process. As a writer develops a scene, the application analyzes the text and surfaces relevant visual references, including images and videos.

How the pipeline works

A debounced text-analysis pipeline waits until the writer pauses before sending text for analysis. An LLM extracts scene context, subjects, environment, objects, mood and visual-search keywords. Those keywords are used to query multiple media APIs in parallel, while backend caching helps reduce redundant requests.

Designing the editor

The application uses a React/Tiptap editor with a live visual panel. The aim is to help writers explore references without leaving the writing interface, while maintaining visual continuity as the scene develops.

What I learned

This project brought together frontend development, LLM integration, API orchestration and product thinking. It highlighted the importance of latency, debouncing, caching and presenting AI-generated results without interrupting the user's workflow.
